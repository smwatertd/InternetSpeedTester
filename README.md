# Замер скорости интернета (тестовое задание)

Консольный скрипт: **10 последовательных GET-запросов** по указанному адресу (**http** и **https**), затем среднее время ответа, суммарный объём и скорость в **МБ/с** (мебибайты в секунду, 1 МиБ = 1024² байт).

## Установка

```bash
cd internet-speed-test
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Пакет `certifi` нужен для корректной проверки HTTPS (в том числе на macOS).

## Запуск

```bash
python3 speed_test.py "https://example.com/large-file.jpg"
```

Дополнительные параметры:

```bash
python3 speed_test.py -n 10 --timeout 120 "https://..."
```

| Параметр | Описание |
|----------|----------|
| `url` | Адрес файла (обязательный) |
| `-n`, `--count` | Число запросов (по умолчанию 10) |
| `--timeout` | Таймаут одного запроса в секундах (по умолчанию 120) |

## Пример вывода

```
Адрес: https://...
Запросов: 10 (последовательно)

  #1: 0,842 с, 2 621 440 байт
  ...
  #10: 0,801 с, 2 621 440 байт

Среднее время запроса: 0,815 с
Объём данных:          26 214 400 байт (25,00 МиБ)
Скорость:              3,07 МБ/с
```

**Скорость** = сумма скачанных байт ÷ сумма длительностей успешных запросов.

## Какой URL выбрать

Нужна прямая ссылка на **статический файл** (картинка, архив и т.п.), а не HTML-страница.

Пример (HTTPS, ~1 МиБ):

```bash
python3 speed_test.py "https://proof.ovh.net/files/1Mb.dat"
```

Пример (HTTP, ~5 МиБ):

```bash
python3 speed_test.py "http://ipv4.download.thinkbroadband.com/5MB.zip"
```

## Ошибки

Скрипт обрабатывает и выводит по-русски, среди прочего:

- неверный или неполный URL, схема не http/https;
- HTTP 4xx/5xx;
- таймаут, обрыв соединения, SSL/TLS;
- пустое тело ответа (предупреждение);
- частичный успех: итог по успешным запросам, код выхода 1, если были неудачные.

Прерывание **Ctrl+C** — сообщение «Прервано пользователем», код 130.
